# 会聚双目立体视觉：让机器人“看向同一点”真正参与深度计算

> Mingshi Chi、John K. Tsotsos，Science Robotics，2026 年 8 月 26 日，DOI：10.1126/scirobotics.aec7205。本文基于正文、补充方法、Data S1 和作者 Zenodo 记录进行中文解读；没有执行作者算法，表中数字是论文报告值。科研示意图为原创生成图，不能作为实验结果使用。

## 一句话看懂：注视方向也提供几何信息

这篇工作的核心是：当机器人两台相机像人眼一样转动、共同注视一个目标时，利用已知相机朝向和注视点约束，直接计算会聚图像中的水平、垂直视差，再恢复三维深度。作者把这套解析方法称为 CBS（Convergent Binocular Stereo），同时建立 49 个场景的 CBS-BM 数据集。

它的价值不只是“摄像头会转”。相机的运动状态成为匹配的先验，使重复纹理、近距离大视角变化等困难场景中的对应关系更容易约束。但这也把电机回差、旋转中心和姿态标定误差引入了深度链路。论文的优势和局限，都来自这份额外的几何信息及其可靠性。

## 1. 器件在哪里：每只眼睛都有独立的 pan 和 tilt

实验头部采用两台 U3-3881LE AF Rev.1.2 相机，配 Corning Varioptic C-S-25H0-096 液体镜头。两眼各有独立水平转动与俯仰，共四个自由度；相机光学中心间距为 11.5 cm。补充材料给出 9.6 mm 焦距、f/3.7 和 2.4 μm 像元尺寸。采集时头部固定在三脚架平台上，只转动相机，不移动底座。[1，p.3；2，pp.6–9]

安装时最关键的约束是相机尽量绕固定点纯旋转、保持基线稳定。普通云台转动时可能同时移动光心，不能直接套用这篇论文的纯旋转假设。补充材料通过标定网格与实际图像中心对应关系检查这一假设；机器人安装到会振动的移动底座后，仍需重新验证标定。[2，pp.5–6]

相机具备可调焦能力，但这项实验并没有展示自动调焦策略：每个场景手动设置一次焦点，随后各注视点使用同一焦点。把硬件具备的功能与论文实际验证的行为分开，才能判断复现需要哪些模块。

## 2. 信号怎样产生：为什么不能只沿同一行找对应点

平行双目经过适当校正后，可以在同一条水平极线上寻找对应点。会聚时，两台相机的光轴相交，成像几何改变：对应物体的位置、尺度和局部形状都可能不同，搜索方向也不必沿图像水平线。CBS 对每个左图像素输出两个分量：水平视差 dₕ = uL − uR，垂直视差 dᵥ = vL − vR。[1，pp.1–2]

在论文的注视与图像中心约定下，双方图像中心指向同一三维点，这个点的视差是 (0, 0)。这里的“零视差”不表示目标在无限远：两眼的会聚角本身已经带有距离信息。对于对称、理想的水平注视几何，目标到基线中点的前向距离可写为 Z = b / [2 tan(α/2)]，其中 b 为基线、α 为两眼视轴夹角。这是帮助理解的几何推导，不能替代任意姿态下的标定与三角化。

这也解释了为什么不能把会聚图像里的 dₕ 直接代入平行双目的 Z = fb/d。前者的视差坐标定义依赖当前注视姿态；实际计算要同时使用像素对应和相机内外参。垂直视差在这里是几何信号的一部分，并非一概作为标定噪声消除。一般非平行或未校正的双目也可出现垂直视差，它不是会聚系统独有的现象。

## 3. 先校准“眼睛朝哪”，再确定搜索范围

电机报告的位置不必精确等于相机光轴朝向。作者使用静止 ChArUco 板，让每个电机从最小值扫到最大值，建立电机数值与相机姿态的映射。每眼采集 21 组标定以覆盖视野和运动范围；在重叠区域，先按各欧拉角分量的均值与标准差筛掉离群估计，再平均剩余旋转估计。[2，pp.2–3]

CBS 将运动标定得到的相对旋转 R、平移 t 与相机内参结合，形成基础矩阵 F。标准表达是 E = [t]×R，F = KR⁻ᵀ E KL⁻¹；其中 E 是本质矩阵。对一个左图像素，F 指定右图对应点应落在哪条极线上，从而把无约束二维搜索缩成沿极线附近的带状搜索。[1，p.10]

论文还利用图像信息修正几何估计：先匹配 SIFT 特征，以电机估计的极线剔除明显错误匹配，再用八点法和 RANSAC 估计另一组基础矩阵。若由两种估计得到的旋转相差超过 5°，就放弃图像估计、回到电机估计。注意，5° 是两种估计的拒绝阈值，不能当作系统精度指标。

实际回位测试中，左眼平均绝对角度误差为 0.533°、右眼为 0.614°，主要来自水平方向。为降低齿轮回差，数据集采集按标定时的同方向运动顺序，从电机最小位置走到目标位置。这种采集条件比机器人任意方向连续扫视更受控，部署时应把回差单独纳入误差预算。[2，pp.3–5]

## 4. Gabor 匹配：把局部纹理转成可比较的响应向量

CBS 不需要训练深度网络。它先在各尺度上匹配满足极线约束的 SIFT 特征，把匹配位置的水平与垂直偏移扩展到特征附近的圆形区域，形成粗先验。多个先验覆盖同一像素时取平均；作者也指出，在物体边界和深度突变处，平均只是近似。图像中心的零视差提供另一个锚点。[1，p.10]

接下来，Gabor 滤波器以不同方向和尺度响应图像中的纹理与边缘。正文列出四个方向 θ = 0、π/4、π/2、3π/4；三个波长 λ = 2、4、8；两个纵横比 γ = 0.5、1.0；两个尺度参数 σ = 1、2；相位 ψ 固定为 0。按这些参数的全组合，可得到 4 × 3 × 2 × 2 = 48 组响应。这个 48 是依据正文参数组合算出的数量，不是神经网络层数。[1，pp.10–11]

每个像素的多组响应组成一个特征向量。CBS 在右图极线附近寻找候选点，比较左右响应向量的平方差之和，选择代价最小的对应点；若已有先验，搜索围绕先验展开，并使用较小范围。用紧凑记号表示，就是 q* = argmin(q∈S) Σk [GL,k(p) − GR,k(q)]²，其中 S 是受几何与先验共同限制的候选集合。

最后，用原始左图引导的加权最小二乘滤波细化视差。因而这条链路包括“特征先验、受约束的匹配、图像引导细化”，而不是仅做 Gabor 卷积就能得到深度。重复纹理本身仍然存在歧义；额外的注视和姿态约束帮助选择更合理的匹配范围，不构成对所有重复场景的保证。

## 5. 从粗到细，再从两个视差分量恢复三维

CBS 构建五层高斯金字塔：level 4 最粗，level 0 对应原尺寸。较粗层提供大范围对应关系，再逐步指导细层；level 2–4 的结果按尺度加权，为 level 1 提供先验，其中较细层权重更大；level 1 的结果再上采样并细化到 level 0。[1，Fig.2，pp.10–11]

粗尺度的作用是减少细节干扰，并为更精细的搜索提供起点；细尺度补充边缘与局部变化。粗层如果已经错误锁定重复图案，错误也可能传到细层，因此多尺度并不自动消除歧义。后续复现要检查先验覆盖、搜索半径、滤波参数和边界处理，不能只照着流程图写几个函数。

输出是左图坐标系中的水平、垂直视差图。把对应像素通过内参还原成射线，再结合两相机位姿进行三角化，就得到三维点与深度。论文讨论这些结果可用于表面倾斜、物体姿态或主动视觉，但没有完成“自动选择下一个注视点 → 驱动眼球 → 执行抓取”的整套任务闭环。注视策略是作者明确列出的后续方向。[1，pp.9–11]

## 6. CBS-BM 如何采集，比较如何对齐

CBS-BM 包含 49 个场景，每场景 5–12 对会聚注视图像，还提供平行图像、平行几何下的水平视差真值和电机信息。近距离子集指中心物体小于 0.5 m；远距离子集指大于 1.5 m；另外包含正常桌面、重复纹理以及高度自遮挡的 TEOS 物体。近距离子集最大的会聚角达到 37°。[1，pp.3–4、7、11]

真值不是算法自己预测的深度。作者用投影机投射 Gray code 结构光，改变投影机位置和相机焦点，每个场景采集 4–12 组。一个像素至少要有两次有效估计；剔除偏离均值超过 2 个标准差的水平视差估计，再平均剩余值，得到平行状态下的真值。这仍受遮挡与结构光覆盖约束，没有真值的区域不参加评价。[1，pp.11–12]

CBS 的输出坐标系与平行真值不同，因此作者先三角化会聚对应点，再旋转回平行参考系，重投影为深度和水平视差；重叠像素取较近深度。各注视点的误差按图像中心的圆形区域聚合：CBS-100、CBS-300、CBS-500 的数字是半径，单位为像素；CBS-inf 使用全图。这些名称既不是模型规模，也不是训练步数。[1，pp.4–5]

CBS 和深度学习比较方法输入 1544×1038 图像；SGBM 与 ELAS 使用较小的 386×259 输入，再放大输出评估。仅统计已赋值、有真值的有效像素，无效区域被排除；补充表 S10 另用 F1 指标描述 SGBM、ELAS 的准确性与完整性。这是一项不同成像配置及既定模型设置的系统比较，不能据此隔离出 Gabor 模块的单独收益。

## 8. Data S1 核查：它是直方图数据，不是完整图像数据集

用户下载的 Data S1 ZIP 内含 aec7205_data_file_s1.xlsx，包含 allFigure6、close、far、normal、repeated patterns、TEOS Objects 六个工作表，每表分为 Disparity Data 与 Depth Data。它提供误差分箱比例；49 个场景的原图、真值、标定和代码则在作者指向的仓储中。

本地核查发现一个值得复现者注意的对应关系疑点：allFigure6 中 CBS-100 的视差分箱 ≥100 px 合计约 15.86%，而正文表 1 的 >100 px 为 15.84%，两者接近；但同一工作表 CBS-inf 的视差分箱 ≥100 px 合计约 50.37%，正文表 1 的 >100 px 为 22.75%，差异明显。后者还有可能涉及字段、单位、版本或聚合方式差异；目前没有原始输出重算证据，不能确定原因，也不能据此断言整项结果错误。

因此，本文主要定量解释采用正文与补充表的标注值，没有自行调换 Data S1 行、不用其疑点数据绘制“校正后”结果。若要复现图 6，需要将 Excel、绘图脚本、原始误差数组和有效像素掩码一起核对；仅检查每行百分比接近 100% 不能确认列标题和单位正确。

## 9. 已知失败模式与工程复现检查

远距离的主要问题是：会聚角变小，同样的角度误差会造成更大的深度误差。补充材料的特定对称注视例子中，0.15° 水平误差在 0.6 m 处对应 0.016 m 深度误差，在 2 m 处对应 0.17 m。这是几何敏感性示例，不能当作全场景精度。增加电机精度、抑制回差、可靠标定，比单纯扩大图像分辨率更切中问题。[2，p.5]

低纹理可能让 SIFT 先验稀疏，错误基础矩阵会使搜索带偏离正确对应；物体边界附近的先验平均与平滑可能混合不同深度；相机光心平移、支架振动和长期机械漂移也会破坏位姿假设。数据集还使用受控灯光、静态场景和人工确认的注视点，尚不能把它的结果直接推广到行走机器人、快速目标或曝光变化很大的户外场景。

作者 Zenodo 记录给出 run_one.py 的运行入口，并说明需要 DIJIT 头部仓储中的相机—电机标定代码。复现时建议按以下顺序检查：[4]

1. 先核对左右相机的标定目录。仓储说明的示例把左右电机标定参数都指向 motors/L，而同一说明明确区分 motors/L 与 motors/R。它是需要检查的示例疑点，不能不看源码就断言应该如何修补。
2. 核对图像尺寸与内参。仓储说明明确说图像缩为原尺寸的 1/2，calib.yml 内参仍为原尺寸；焦距和主点必须与实际输入尺寸一致。
3. 用一个场景、一个注视点验证几何、视差方向与平行参考系对齐，再扩展到全数据集。
4. 同时记录输入尺寸、有效像素覆盖、运行时间、峰值内存和精度。仓储提醒代码可能占用大量内存；本次未下载并执行约 2.00 GB 的算法/数据压缩包及约 17.45 GB 的 plots.zip，因此不宣称已经跑通，也没有实测帧率。
5. 最后核对 Data S1 和图表聚合是否来自同一版本，再评价是否重现论文结论。
