# Public video attribution

The seven MP4 files in this directory were extracted from `Supplementary Material Videos.zip` in:

Danna Ma, Kirstin Petersen, Baxi Chong, and Daniel Goldman (2026), *Data from Cross-link collective: Entangled robotic matter with cohesive motion*, Zenodo, [https://doi.org/10.5281/zenodo.18271890](https://doi.org/10.5281/zenodo.18271890), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Site changes: all seven source videos were transcoded from 1920×1080 H.264/AAC to 1280×720 H.264/AAC, reduced in bitrate, and rewritten with the MP4 `moov` atom at the beginning for web streaming. The scientific sequence and playback speed were not changed.
