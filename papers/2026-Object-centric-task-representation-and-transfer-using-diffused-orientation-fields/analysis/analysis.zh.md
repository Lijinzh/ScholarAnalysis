# 基于扩散方向场的物体中心任务表示与迁移

> 最重要的结论：这篇论文不是训练一个更大的端到端策略，而是在机器人与策略之间加入一层**随物体曲面连续变化的局部坐标系**。切片、削皮、擦拭或探测仍可写成简单的“沿表面走、向表面压、朝关键点移动”；换了香蕉、黄瓜、梨、弯管或复杂点云后，只重新计算方向场，不重新学习动作本身。

## 一句话看懂：曲面为什么让技能迁移变难？

在平面上，“向右移动”“垂直向下切”“离表面 5 mm”都可以用同一个全局坐标系表达。到了香蕉、梨、碗或任意弯曲外壳，表面切向、法向和“朝目标端点”的方向会随位置改变。若机器人仍照抄世界坐标中的轨迹，工具就会离开表面、切入物体，或者以错误姿态接触。

作者把需要迁移的内容拆成两部分：

1. **与形状无关的局部动作**：例如沿局部 `x` 轴滑动、沿局部 `z` 轴接近表面、到达端点后反向。
2. **与当前形状有关的几何脚手架**：由点云和少量关键点在线计算出的扩散方向场，为工作空间每个查询位置给出一个局部参考系。

这样，动作描述保持不变，方向场负责把局部动作实时旋转到当前物体的全局姿态中。

## 系统里实际有哪些硬件？

真实实验使用六自由度 uFactory Lite 6 机械臂、Intel RealSense D415 深度相机、Bota Systems SensONE 六维力/力矩传感器，以及为刀、削皮器和探针制作的 3D 打印夹具。深度相机提供在线点云；算法给出局部参考系；高层模块生成局部动作；底层导纳控制器跟踪位置、姿态和接触。

这说明 DiffOF 不是直接输出电机电流，也不是用扩散模型生成整段动作。它输出的是可被遥操作、轨迹优化器、动作原语或强化学习策略共同查询的**几何中间表示**。

## 核心数学：怎样从两个点长出整片局部坐标系？

### 1. 把关键点写成扩散初值

闭合或近闭合物体通常选两个语义端点：一个源点记为 `+1`，一个汇点记为 `-1`，其他点为 `0`。对于有开放边界的覆盖任务，边界点本身可作为条件。关键点可以人工指定、由几何边界自动提取，或在补充实验中用 DINOv2 从源图像零样本迁移。

点云记为 `P={xᵢ}`。作者在点云的局部切平面上构造质量矩阵 `M` 和弱拉普拉斯矩阵 `C`，用隐式时间步求解扩散：

```text
uτ = (M - τC)⁻¹ M u₀
```

这里的 `τ` 是控制平滑程度的扩散参数，不是算法耗时，也不是机器人动作时间。较小 `τ` 保留局部几何细节；较大 `τ` 更强地抑制高频噪声，并突出物体的全局对称结构。

### 2. 从标量梯度构造正交局部坐标系

扩散后的标量场沿曲面的梯度给出“从源到汇”的切向方向：

```text
e₁ = ∇uτ
e₃ = n
e₂ = e₃ × e₁
```

`n` 是表面法向。按 `e₁, e₂, e₃` 排列后得到行列式为正的旋转矩阵，也就是曲面每一点的局部参考系。补充材料还讨论了直接扩散有方向关键点和完整姿态关键点的方法；完整姿态需要在 `SO(3)` 或其李代数上处理，不能把三个轴独立平滑后就假定它们仍然正交。

### 3. 用 Walk on Spheres 把表面方向扩散到自由空间

削皮和切片都包含“先从自由空间接近，再进入接触”的阶段，所以仅有表面坐标系不够。作者没有把整个三维工作空间体素化，而是用无网格 Monte Carlo 方法 Walk on Spheres（WoS）按查询点求解拉普拉斯方程：随机路径从查询位置不断跳到最大内接球面，直到抵达物体边界，再读取边界姿态。

多个随机样本到达不同边界点后，作者将对应旋转写成单位四元数，并用 Markley 四元数平均求一个代表姿态。点云通过 k-d tree 支持最近点查询；这一步只在机器人当前需要的查询位置计算，不必预先生成整个三维场。

## 为什么它比“最近表面坐标系”更稳定？

最直接的替代方法，是把工作空间查询点投影到最近表面点，然后复制该点的局部姿态。但两个空间位置很近的查询点，可能投影到曲面上相距很远的位置，于是参考系突然跳变。补充材料报告，最近帧基线的邻域平均角度差约为工作空间扩散的 **1.5 倍**；对接触控制而言，这种不连续会变成工具姿态突变、力峰值和抖动。

作者还比较了两种替代路线：

- **关键点向量投影**：把指向关键点的向量投影到切平面。它在 Spot 点云上产生 9 个非预期源/汇奇点，而且不能正确遵循曲面测地路径。
- **欧氏空间扩散后再投影**：方向虽然平滑，但扩散过程没有看曲面内在几何；在 T 形凹面上，方向会穿过凹陷而不是沿表面绕行。

DiffOF 的要点不是“做了平滑”这么简单，而是先沿曲面内在几何扩散，再把边界姿态调和延伸到工作空间。

## 局部动作如何变成切片、削皮和覆盖？

作者把动作写成由距离触发切换的局部闭环原语：距离关键点多远、距离表面多远，决定当前处于接近、接触、沿面运动、退回还是反向阶段。切片可重复执行局部上下动作；削皮沿端点之间的局部切向移动；覆盖让探针沿边界约束下的蛇形路径扫描。

这种分解允许同一方向场接入不同控制范式：

| 高层来源 | 如何使用方向场 | 论文展示的作用 |
| --- | --- | --- |
| 局部动作原语 | 在局部坐标系中写有限状态闭环动作 | 切片、削皮、触觉覆盖跨对象迁移 |
| SpaceMouse 遥操作 | 把手柄轴映射为沿表面、朝表面和朝关键点运动 | 操作者无需持续手动修正工具姿态 |
| 轨迹优化 | 用表面距离和到关键区域的测地距离构造代价与梯度 | 表面跟随、目标到达和避障；方向场用于 warm-start |
| 强化学习 | 在局部参考系中定义观测、动作或奖励 | 在二维圆上训练的策略零样本迁移到方形和三维点云 |

## 论文真正证明了什么？

### 1. 连续场显著降低跨形状动作方差

作者把一个梨点云随机做各向异性缩放、二次弯曲和扭转，生成 50 个实例，并把三周期削皮动作投到不同坐标表示中。Data S1 显示，单一物体固定坐标系的平均速度标准差约为 **0.326 mm/s**，DiffOF 局部坐标中的标准差约为 **0.043 mm/s**，约低 **7.5 倍**。

增加离散局部坐标系数量会逐步逼近连续场，但代价很直观：最近帧方案从 2 个坐标系时的约 `0.365 mm/s` 降到 2048 个时的约 `0.047 mm/s`，才接近 DiffOF 的 `0.043 mm/s`。这支持作者的观点：DiffOF 相当于“无限密、连续且平滑”的局部参考系，而不是若干关键帧的硬切换。

### 2. 几何 warm-start 明显减少优化迭代

在 50 个不同初始位置的轨迹优化实验中，方向场提供的测地射击轨迹被用作 warm-start。Data S1 中第 0 次迭代的控制变化范数均值从冷启动的约 **1.255** 降为约 **0.257**；论文报告 warm-start 通常 1 次迭代即可收敛，而冷启动至少需要 5 至 6 次。这里证明的是初始轨迹更接近几何可行解，不是 DiffOF 替代了完整动力学或碰撞约束。

### 3. 抗噪来自低通平滑，但最强平滑不总是最好

作者分别进行 50 次拓扑、几何和关键点噪声试验：移除一半点云并打 10 个半径 5 mm 的孔；给点位置加入 `σ=3 mm` 高斯噪声；给两个关键点加入 `σ=20 mm` 高斯噪声。随 `τ` 增大，三类 RMSE 总体明显下降。

Data S1 也显示过度增大 `τ` 并非无限受益。拓扑噪声 RMSE 从 `τ=0.1` 时约 `0.0277` 降到 `τ≈774` 时约 `0.00088`，随后在 `τ=10000` 回升到约 `0.00129`；关键点噪声也在 `τ≈774` 附近达到最低后轻微回升。`τ` 因此是“局部细节—全局平滑”的任务相关旋钮，不应只追求最大值。

### 4. 削皮实验说明几何迁移有效，但尚不是全自主成品

补充材料的任务级结果如下：

| 对象 | 连续削皮长度 | 削皮面积 |
| --- | ---: | ---: |
| 黄瓜 | 1.00 | 0.97 |
| 西葫芦 | 1.00 | 0.89 |
| 胡萝卜 | 0.86 | 0.95 |
| 梨 | 0.79 | 0.96 |
| 红薯 | 0.95 | 0.95 |

黄瓜和西葫芦上的结果可与训练了 60 次示范的 Reactive Diffusion Policy、训练了 438 次示范的 ForceMimic 做同类对象比较；DiffOF 不需要示范训练。但不能把这张表解释为“DiffOF 已全面超过模仿学习”：不同论文的硬件、控制器与对象并不统一；本论文还由人工协助夹具，防止物体转动和线缆缠绕，并在完成一面后人工重新调整物体和标注端点。

硬皮胡萝卜、红薯与软皮梨的连续削皮长度下降，作者将其归因于材料差异和同一组导纳参数没有针对软硬度重新调节。DiffOF 解决的是几何坐标迁移，不会自动学会合适的接触力、刀具摩擦和材料顺应性。

### 5. 在线计算可行，但实时数字要按组件理解

补充材料在 Apple M1 Pro、32 GB RAM、纯 Python CPU 实现上报告：

| 点云 | 点数 | 拉普拉斯构造 | 因式分解 | 表面扩散 | 单次 WoS 查询 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Bowl | 3,000 | 58 ms | 10 ms | 0.3 ms | 4 ms |
| Spot | 6,000 | 133 ms | 27 ms | 0.6 ms | 7 ms |
| Bunny | 12,000 | 244 ms | 44 ms | 1.1 ms | 26 ms |

WoS 每个查询使用 256 个样本。四个各 12k 点物体的复杂场景预处理仍低于 1 秒。刚体运动和不拉伸弯曲属于等距变换，离散拉普拉斯可以复用；但如果软体形变改变了测地结构，就需要更新。作者提出 GPU 并行可让多查询扩展更好，但本论文没有给出完整 GPU 闭环延迟基准。

## 关键点到底是不是新的瓶颈？

是，但它比完整轨迹对应更稀疏、可解释。切片和削皮只需对象两个端点；覆盖任务使用开放边界。补充材料的自动端点/边界提取不需要训练；DINOv2 关键点迁移只是概念验证，六个匹配的置信度约为 `0.596` 至 `0.809`，并没有证明在遮挡、相似纹理、强视角变化和新类别下始终可靠。

如果关键点语义错了，方向场仍可能很平滑，却平滑地指向错误任务方向。工程系统应把关键点置信度、对象分割和接触反馈纳入失效检测，而不能把“场连续”当成“任务正确”。

## 最明确的失败模式

- **透明、半透明和高反物体**：D415 点云缺失或畸变时，扩散只能平滑已有信息，不能重建不存在的表面。
- **遮挡导致拓扑断裂**：电缆把香蕉点云分成两个不连通分量时，扩散会沿错误边界传播并导致切片失败；作者用 Grounded SAM 做了修复概念验证。
- **固定 TCP 假设**：系统执行前需要精确标定工具中心点；真实削皮中接触点可能沿刀刃移动，论文尚未在线估计有效 TCP。
- **WoS 表达能力受限**：拉普拉斯方程给出满足边界条件的最平滑场，稳健但难表达高度局部化结构；作者建议探索 screened Poisson equation。
- **形变并未被完整验证**：拉普拉斯对等距弯曲可复用是理论与几何性质，但衣物、线缆和软体接触会改变测地结构，论文没有做系统实验。
- **统计结论有限**：论文没有正式假设检验，使用均值、标准差、RMSE 和描述性比较；多个机器人实验仍属于 proof-of-concept。

## 如果要复现，建议按什么顺序？

### 最小算法原型

1. 从作者 MIT 代码的仿真脚本开始，不先上真实刀具。
2. 读取一个 3k 至 12k 点的弯曲对象点云，体素下采样先用论文的 **3 mm**。
3. 手工设置一源一汇两个端点，构造点云拉普拉斯 `M, C`。
4. 用 `τ=1000` 生成表面方向场；覆盖任务可先试补充材料的 `τ=10`。
5. 实现 k-d tree 最近点查询、256 样本 WoS 和四元数平均，在表面上方不同高度验证姿态连续性。
6. 先画出局部 `x` 方向和查询轨迹，检查是否存在非预期奇点、凹面穿越和最近帧跳变。

### 真实机器人最小闭环

1. 使用钝头探针和软仿真物体替代刀和削皮器，先验证覆盖与恒距运动。
2. 标定相机外参、SensONE 零偏、工具 TCP 和工具坐标轴；记录毫米级误差如何进入点云与接触力。
3. 补充材料使用的位置刚度为 `[400, 200, 200] N/m`，转动刚度为 `[10, 10, 20] Nm/rad`；只能作为起点，不能原样照搬到另一机械臂和工具。
4. 分层验收：点云质量 → 关键点正确性 → 表面场连续性 → 工作空间场连续性 → 无接触轨迹 → 低力接触 → 材料任务。
5. 对透明/高反对象、点云断裂、关键点误配、TCP 漂移设置明确拒绝条件和人工急停。

### 复现成本的真正重点

算力不是最大门槛。更难的是稳定的深度点云、相机—机器人外参、工具 TCP、接触控制与对象固定。作者公开的 Zenodo ROS bag 总计 **24.5 GB**，包含胡萝卜、黄瓜、梨、红薯和西葫芦削皮记录，可用于离线回放和力/力矩分析；代码仓库使用 Git LFS 保存模型与大文件，安装说明要求 Python 3.12，并依赖独立的 `diffused_fields` 库。

## 这篇工作的最佳定位

DiffOF 更像机器人操作系统里的“几何坐标服务”，而不是一个万能策略。它把表面法向、到关键点的测地方向、自由空间接近方向和局部姿态统一成可查询的连续场，让已有的遥操作、规划、动作原语和学习策略少承担一部分几何泛化负担。

最有前景的组合不是 DiffOF 与学习二选一，而是：DiffOF 负责可解释的曲面几何和坐标规范化，学习方法负责关键点检测、材料相关顺应性、动态 TCP、复杂长时序决策与不确定性判断。论文已经证明这层几何脚手架有用，但距离无人工重定位、无人工夹具、适应透明软体并自主处理工具接触变化的通用系统仍有明显距离。
