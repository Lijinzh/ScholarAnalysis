# Dryad public-domain subset

The files in this directory are an analysis-focused subset of:

- Bird, Christopher; Bo, Antonio; Lu, Wei; Dick, Taylor (2026), “Data from: Ultra-wideband radar to measure in vivo muscle forces”, Dryad, https://doi.org/10.5061/dryad.sbcc2frmh
- License shown by Dryad: Public domain, CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/

Included files support the figures and model description on this paper-analysis page. The complete Dryad dataset is about 2.61 GB and remains available from the official repository.
